# Local image library / 本地图库

This directory is the input library for the earlier batch publisher and optional development workbench images. Actual operational images are not distributed in Git. Add your own PNG/JPEG/WebP files locally; they remain ignored.

此目录保留早期发布器使用的本地图片入口。平台的正式图库由后端 `DATA_DIR` 管理，通过 Dashboard 上传或批准的 GPT Image 2 任务入库；不能把这里的文件路径直接当作平台素材 ID。

The production documentation screenshots are maintained separately in `docs/product/screenshots/`. They are product illustrations, not default publishable media.
