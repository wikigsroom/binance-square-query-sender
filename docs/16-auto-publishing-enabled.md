## “全局发送已暂停”的含义

数据库中的全局暂停状态会拦住全部账号新建实际发送任务，包括手动一次与自动计划；Worker 进程仍可存活，预览和只读查询仍可使用。此外，服务器的 `SQUARE_PUBLISH_ENABLED` 决定是否允许调用真实发布传输，两者是独立开关。

本次按用户要求，将全局暂停改为关闭，将服务器真实发布传输改为开启，并启用现有全部7个账号的自动计划。

## 采用的样例

样例是 `广场账号 54C65AD8`。检查时它是唯一已经绑定有效预设的账号，其余6个账号绑定为空。

按样例复制预设及权重，不复制账号 API Key、身份资料或固定的到期时间。所有账号各自重新抽取间隔。

样例选用的8种预设：逆向审视、GameFi 与应用、AI 与 DePIN、Solana 生态、以太坊与 DeFi、比特币宏观、精品长文、News 拆解。使用的是用户当前选择的预设记录与已发布版本。

## 操作与核验

先备份专用 PostgreSQL 数据库、服务器环境配置及原账号配置，再在全局暂停状态下同步账号绑定与周期。修改服务器发布传输后重启本应用，确认传输与 Worker 正常，再解除全局暂停，使每个账号独立抽样。

核对全局暂停为 `false`、真实传输为 `true`、Worker 为 `running`，7个账号均可用、无阻塞、周期启用，且绑定与样例一致。浏览器核验只读取状态，结束后关闭本轮浏览器。
