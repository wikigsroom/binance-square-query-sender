## 已确认的产品基线

1. 所有用于发送的正文必须经过指定 AI 模型生成或编辑成稿；首个文字模型为 `gpt-6-luna`，保留接入其他明确指定模型的能力。
2. 发布图片只使用托管图库中的已有图片，或由批准的 `GPT Image 2` 生图任务生成并入库的图片。
3. Dashboard 统一管理本人多个账号的币安广场 API Key。
4. 系统管理经本平台产生的帖子，支持多条件检索、状态追踪和来源追溯。
5. 用户可以配置多个内容风格预设，控制方向、语气、素材、数据源、文字长度和配图要求。
6. 各账号分别配置随机发布间隔上下限，分别维护下一次执行时间。
7. 首版部署到远程服务器。
8. 同一账号可以绑定多个预设，每次任务按配置权重随机选择一个。

## 本轮文档的工作边界

文档统一保存在 `docs/`。后续新开发代码、数据库迁移、部署配置和新运行数据统一组织在 `app/`；现有根目录脚本和素材是迁移来源。

本轮完成需求清洗和设计文档，不执行平台部署、密钥导入或发布任务。文档中的页面、接口、表结构和阶段划分属于开发契约草案；具体服务器系统、容量目标及外部接口能力见待定项。

## 阅读时的状态约定

- **已确认**：用户本轮或当前对话直接要求的内容。
- **继承**：对话中仍有价值的现有业务要求，须按文档指定范围沿用。
- **建议默认**：为使方案可实施而给出的默认行为，可以调整。
- **待定**：缺少外部信息或仍需用户决定，不得作为已确认能力对外承诺。

功能优先级中 P0 表示首版闭环必须具备，P1 表示首版闭环后的增强项。P0 的最终完成标准以 07 中的验收案例为准。
