# 02 · Dashboard 页面与交互规格

本文件描述首版产品交互，不指定视觉设计稿或前端组件库。所有按钮行为均由后端校验和记录，不能仅靠页面隐藏控制发布权限。

## 信息架构

| 页面 | 主要问题 | 核心内容 |
| --- | --- | --- |
| 总览 | 现在运行正常吗，接下来谁会执行？ | 账号概况、今日发布、待核验、阻塞、调度与工作进程心跳、下一批到期任务 |
| 账号 | 管理哪些账号，各自何时和按什么规则发送？ | 账号、凭据状态、多预设权重、间隔、下一次时间、近期任务 |
| 内容预设 | 每类文章如何选材、写作和配图？ | 规则编辑、版本、绑定账号、测试预览、完整合成提示词 |
| 图库与生图 | 图片从哪里来，生成到哪一步？ | 已有图库、筛选与使用记录、GPT Image 2 任务 |
| 帖子中心 | 发了什么，能否找到并追溯？ | 多条件检索、正文与图片、发布/核验状态、详情 |
| 任务与日志 | 哪一步执行或阻塞，是否可以恢复？ | 队列、阶段、重试、原始错误、进程心跳 |
| 系统设置 | 模型、数据源和全局运行规则是什么？ | 管理员、服务连接、批准模型、数据源、全局暂停、并发和限额 |

## 总览

显示账号总数、调度启用数、暂停数、凭据异常数；今天发布确认数和公开核验通过数分别统计。失败、结果不明和待核验不能合并为一个红色“失败”。

下一次任务列表按 `nextDueAt` 排序，展示账号、间隔范围、已抽中的到期时间、倒计时、是否阻塞和阻塞原因。预设在到期认领任务时才抽取，尚未抽取时显示“届时按权重选择”，不得展示虚构的选中结果。

全局暂停入口始终可见。暂停会阻止新的发送提交；已在外部提交的请求继续回收结果并核验，界面说明其真实状态。

## 账号管理

### 列表字段

账号名称、分组/标签、平台 UID（已获取时）、Key 掩码与版本、凭据健康、调度状态、间隔上下限、下一次执行、最后确认已发时间、最近错误，以及绑定预设摘要。

支持名称/UID/标签检索和状态过滤，账号详情的所有历史使用稳定内部 `accountId` 关联。

### 新建与凭据

新建字段：名称、备注、标签、广场 API Key。可逐个录入，批量导入首版可通过文本粘贴或受控导入完成，逐行返回新增、重复、格式错误和已存在账号匹配结果。不得将导入的原始 Key 写入浏览器本地存储。

2026-10-22 批量导入规则更新：输入区仅需每行一个 API Key，无需名称、UID、标签或备注。自动忽略空行与首尾空白，后端自动生成账号名称；每批最多1000个，重复与错误逐行报告并保留原始粘贴行号。导入后账号自动计划暂停。单账号表单仍支持原有资料字段。

新账号默认暂停。界面将“格式已保存”“只读验证通过”“最近发布认证通过”分别展示；若接口不提供无发送副作用的验证能力，不用发一条帖子来验证 Key。

轮换 Key 保持账号 ID、历史、预设绑定和调度配置不变。已开始提交的任务保留实际使用的凭据版本；下一次提交使用当前有效凭据。凭据明确无效时只阻塞对应账号。

### 预设绑定

逐条选择预设、启用开关和权重。显示参与抽样的有效预设及换算后的选中概率；权重为0表示不参与，全部有效权重合计必须大于0。

绑定跟随预设的当前已发布版本；任务创建时冻结具体版本。编辑草稿预设不会改变生产绑定，发布新版本后影响新任务。

### 调度编辑

字段：最小间隔、最大间隔、单位、启停、下一次已抽中时间。页面换算成分钟/秒并校验边界，保存到后端使用整数秒。

操作包括启用、暂停、恢复、按当前规则重排下一次、立即执行一次。展示本次已抽中的间隔和参考起点；不能每次页面刷新都改变倒计时。

保存规则后，建议默认只影响下一次抽样；“立即重排下一次”是单独操作。规则改变与任务到期并发时，以后端版本校验结果为准。

## 内容预设编辑器

| 分区 | 字段 |
| --- | --- |
| 基本信息 | 名称、描述、启用状态、版本、批准文字模型 |
| 内容方向 | 主题/币种范围、选材规则、叙述视角、语言、语气、观点边界、禁止项 |
| 文字约束 | 优先字符区间、硬上限、段落偏好、标签数量及规则、必要事实字段 |
| 数据与素材 | 数据源、新闻优先级、必需/可选、时效、缺失策略、可选参考资料 |
| 图片规则 | 来源模式、图库集合/标签、生成模型、风格、比例、复用窗口、素材不足策略 |
| 质量检查 | 禁词、重复检测窗口、事实对应关系、允许的模型修复次数 |
| 模型参数 | 连接与模型引用、请求参数；只展示经该适配器验证可用的参数 |

预设保存草稿和发布版本是两个动作。页面展示本版本与上一版本的规则差异，以及受影响的绑定账号。

“测试预设”执行取材、AI 写作、配图选择和校验，返回预览任务，不发布。涉及新生图时使用明确的“包含生图”选项，展示模型及估算/实际用量（可获取时）。

预览展示实际全文、Unicode 字符数、图片、标签、事实、新闻来源、模型、完整合成提示词和失败项。新增写作要求通过 AI 改稿；直接手动修改发送字段后，页面标记“需要重新 AI 成稿”。

## 图库与生图

图库支持缩略图/列表，按来源（已有图库、GPT Image 2）、集合、标签、风格、比例、入库时间、可用状态和最近使用时间筛选。

图片详情显示来源和文件摘要、关联生图任务、使用账号/帖子、元数据。被历史帖子引用的图片不直接破坏性删除：先停用，保留历史追溯；物理清理由保留策略决定。

生图任务创建字段：批准图片模型、提示词/素材说明、风格、比例/尺寸和数量；可关联预设或帖子任务。任务列表展示状态、等待时间、错误、请求标识和入库结果。生成中不能显示为“已有可发图片”。

远程部署时，用户电脑上的图片通过上传进入服务器图库；页面不得直接引用电脑盘符作为服务端图片路径。

## 帖子中心与搜索

### 列表与过滤

| 过滤项 | 匹配定义 |
| --- | --- |
| 正文关键词 | 首版为去除首尾空白后，对最终正文做中文连续子串匹配；与其他条件 AND 组合 |
| 账号/分组/标签 | 可多选；同字段内 OR，不同字段间 AND |
| 代币/主题 | 标准化代币标签精确匹配，非仅在正文随意找一个相似缩写 |
| 预设与版本 | 可查询同一预设全部版本，或指定版本 |
| 模型/服务连接 | 按实际生成任务中的模型及连接引用查询 |
| 日期范围 | 明确选择创建时间或确认发布时间；界面时区转为 UTC 查询 |
| 状态 | 发布与核验分别筛选 |
| 远端标识 | 支持准确帖子 ID 或本系统存储的帖子链接查询 |

默认按创建时间倒序，使用 ID 作为同时间记录的第二排序键。筛选条件与分页可通过页面 URL 恢复。无结果显示实际筛选条件，不能将网络错误显示为“没有帖子”。

### 详情

左侧显示最终发送内容和图片，右侧显示账号、预设版本、模型/请求、数据快照、来源和时间线。发布阶段展示远端回执与公开链接；核验阶段展示文字、标签和图片的比对结果。

“重新核验”只执行读取；“AI 改稿/新建一条”创建新的内容版本或任务。已发内容不会因为修改本地记录就变成远端编辑成功。

## 任务与错误呈现

每个任务显示账号、触发方式、选中预设和概率、计划时间、开始/结束时间、当前步骤、重试次数、锁/租约和下一次尝试时间。

错误详情必须包含具体阶段、分类、HTTP/平台错误码、去除敏感字段后的原始消息、发生时间和可执行动作。按钮由后端返回能力决定，例如“重新核验”“更新凭据”“重新生成”“恢复调度”；不存在可安全重试的依据时不显示直接重发。

## 通用交互

异步操作返回任务 ID，页面可刷新和恢复进度；重复点击由后端幂等处理。数据加载、空数据、权限不足、失联、运行中和失败均有明确呈现。后台服务失联时展示最近心跳时间，不能仅凭页面打开就显示“服务运行中”。
